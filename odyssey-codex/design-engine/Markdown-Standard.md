# Markdown Standard

## Definition

The Markdown Standard defines how every Odyssey document should be written.

Its purpose is to ensure consistency, readability, maintainability, and AI compatibility across the entire Odyssey Codex.

This standard does not define system logic.

It defines documentation structure.

---

# Purpose

The Markdown Standard exists to:

- Keep every document visually consistent.
- Improve readability.
- Simplify maintenance.
- Help AI understand system relationships.
- Create a unified documentation language.

---

# Why

As Odyssey grows, hundreds of documents will be created.

Without documentation standards, every contributor may write differently.

Consistent documentation is easier to maintain than individually optimized documents.

---

# What is NOT

The Markdown Standard is NOT:

- A System
- A Framework
- A Formula
- A UI Standard
- A Coding Standard

It only defines how documentation should be written.

---

# Current Standards

## 1. Structure Diagrams

All system structures should use `text` code blocks.

Example:

```text
Total Performance (100%)

├── Class Performance (50%)
│   Professional performance within a member's own Class.
│
└── Guild Performance (50%)
    Contribution beyond a member's Class responsibilities.
```

Use this format for:

- Frameworks
- Architecture
- Relationship
- Progression
- Profession Trees
- Organization Structures
