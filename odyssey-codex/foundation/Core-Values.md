# Core Values

## Definition

The Core Values are the non-negotiable principles that govern every decision inside Odyssey.

Every conflict, every trade-off, every difficult call is resolved by returning to the Core Values.

---

# Purpose

The Core Values protect the identity of Odyssey as it grows.

Systems will evolve. People will come and go.
The Core Values remain.

Currently under discussion.

# Recovery Note

The Core Values are the constitution of behaviour.
If ever lost, restore them before restoring any system.
