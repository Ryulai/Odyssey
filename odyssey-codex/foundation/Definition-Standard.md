# Definition Standard

## Definition

Every concept inside Odyssey must have a complete definition before it can become an official concept, system or language.

A definition is not merely an explanation.

It defines the scope, purpose, boundaries and identity of a concept.

---

# Purpose

The purpose of a definition is to eliminate ambiguity.

Different people should reach the same understanding after reading the same definition.

Definitions preserve intention.

They prevent future misunderstanding and design drift.

---

# Why

A simple sentence rarely explains a concept completely.

For example,

"Business is buying and selling."

Although correct, it fails to explain its purpose, boundaries and value.

Odyssey adopts complete definitions so future designers understand not only **what** something is, but also **why** it exists.

---

# Definition Principles

Every official definition should answer:

- What is it?
- Why does it exist?
- What problem does it solve?
- What is it NOT?
- What value does it create?
- What are its boundaries?

---

# Compass Protocol Requirement

Before a definition can be frozen,

it must pass the Compass Protocol.

Only after the Compass Protocol has been completed should the official definition be written.

# Current Standard

Every new:

- Keyword
- Language
- Framework
- System
- Rule
- Project
- Methodology

must include an official definition.

No exceptions.

---

# Future

As Odyssey expands,

the definition template may evolve.

However,

the requirement that every official concept must have a definition will never change.

---

# Recovery Note

If the original discussion is lost,

the official definition should always be considered the highest reference.

Definitions preserve the original design intention across future generations.
