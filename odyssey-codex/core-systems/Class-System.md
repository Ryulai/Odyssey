# Class System

## Definition

The Class System defines the professional identity and long-term growth path of every Odyssey member.

It is the central operating system of Odyssey.

Every member belongs to one Main Class and progresses through a standardized growth journey.

The Class System connects all major systems into one unified ecosystem.

---

# Purpose

The Class System provides every member with:

- Identity
- Direction
- Growth
- Progression
- Opportunity

Instead of simply assigning a job title,

Odyssey creates a professional journey.

---

# Why

Traditional organizations define people by their position.

Odyssey defines people by their growth.

A person's profession should not only describe what they do today,

but also who they can become tomorrow.

---

# What is NOT

The Class System is NOT:

- A job title
- An organization chart
- A salary grade
- A department structure

It is a professional growth system.

---

# Five Core Systems

The Class System consists of five independent systems.

## 1. Performance System

Measures current contribution.

Current period evaluation.

---

## 2. Ranking System

Measures accumulated long-term growth.

Ranking is permanent under normal circumstances.

---

## 3. Secondary Class System

Allows members to learn additional professions after sufficient growth.

---

## 4. Mentorship System

Develops the ability to grow other people.

Currently under design.

---

## 5. Ownership System

Develops organizational ownership and leadership.

Currently under design.

- Trust before Opportunity.

- Learning never stops.
