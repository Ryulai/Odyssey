# Secondary Class System

## Definition

The Secondary Class System allows an Odyssey member to learn and develop additional professional disciplines after demonstrating sufficient growth in their Main Class.

It expands capability rather than replacing identity.

Every member always owns one Main Class.

Secondary Classes are additional growth paths.

---

# Purpose

The Secondary Class System exists to:

- Encourage continuous learning.
- Develop cross-functional capability.
- Prepare future leaders.
- Increase organizational flexibility.

Odyssey believes great leaders understand more than one profession.

---

# Why

Traditional organizations usually define employees by a single role.

Odyssey believes growth should not stop after mastering one profession.

Members who consistently demonstrate responsibility should have opportunities to broaden their abilities.

---

# What is NOT

The Secondary Class System is NOT:

- Department transfer
- Job hopping
- Promotion
- Temporary assignment
- Replacement of Main Class

It is a structured learning and growth system.

# Current Rules

A member may only unlock a Secondary Class after reaching Gold Rank.

Every application requires approval.

Every Secondary Class requires a 30-day probation period.

After passing probation,

the Secondary Class becomes officially activated.

Status:

🧊 Frozen

---

# Independent Progression

Every Secondary Class owns its own:

- Performance
- Ranking
- Growth History

Progress in one profession should not automatically transfer into another.

Each profession must be earned independently.

Status:

🧊 Frozen

---

# Growth Philosophy

Odyssey rewards responsibility before opportunity.

Members first prove reliability.

Only then are they trusted with broader responsibilities.

Learning is considered a privilege earned through growth.

Future versions may allow multiple Secondary Classes.

# Design History

Originally,

Secondary Class was considered a simple department transfer.

During discussion,

it evolved into an independent professional progression system.

Each profession now owns its own Performance and Ranking.

This became one of the defining characteristics of Odyssey.
