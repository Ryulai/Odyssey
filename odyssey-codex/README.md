# Odyssey Codex

> Single Source of Truth for the Odyssey Project.

## Purpose

The Odyssey Codex is the official knowledge repository of the Odyssey ecosystem.

It records:

- Philosophy
- Constitution
- Design Engine
- Core Systems
- Shared Language
- Frameworks
- Decision Logs
- Parking Slots
- Roadmaps
- Recovery Notes

Every design discussion, frozen decision, rejected proposal, and future concept should be documented here.

This repository is the brain of Odyssey.

The application (Lovable) is the body.

If the application is lost, Odyssey can always be rebuilt from this Codex.
