# Shared Language

## Definition

Shared Language is the official vocabulary of Odyssey.

Every important concept should have a unique name with a unique meaning.

The purpose is to create fast communication, consistent understanding and a shared organizational culture.

Language is one of the operating systems of Odyssey.

---

# Purpose

Words create understanding.

When everyone uses the same language,

everyone thinks in the same direction.

Shared Language reduces misunderstanding and increases communication efficiency.

---

# Why

Different people often describe the same concept using different words.

Over time,

this creates confusion.

Odyssey creates one official vocabulary so every member understands the same meaning.

---

# Principles

Every official language should satisfy the following principles.

## Clear

Easy to understand.

---

## Consistent

One word should only represent one concept.

---

## Memorable

Simple enough to remember.

---

## Expandable

Able to support future systems.

---

## Contextual

The meaning should match the philosophy of Odyssey.

# Naming Standard

Every official keyword should:

- Have a Definition.
- Have one meaning.
- Avoid duplicate interpretation.
- Support future expansion.
- Be recorded inside the Codex.

---

# Design History

Originally,

language was considered only a naming convention.

Later,

it became clear that language itself is one of the foundations of Odyssey culture.

Shared Language is now recognised as a core layer of the ecosystem.
