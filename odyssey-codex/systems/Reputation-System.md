# Reputation System

## Definition

The Reputation System will measure how a member is perceived by peers, mentors and leaders across the guild.

Unlike Performance, which measures contribution, Reputation measures trust.

---

# Purpose

To formalize the social capital that already flows informally inside Odyssey.

---

# Current Status

🔒 Locked for future development.
No design work has begun.
The system is reserved so that its concept, name and slot in the architecture remain protected.

---

# Recovery Note

Do not confuse Reputation with Performance or Ranking.
Reputation is a separate axis of measurement.
