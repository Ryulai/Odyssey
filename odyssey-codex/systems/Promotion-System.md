# Promotion System

## Definition

The Promotion System defines how a member advances from one Rank to the next inside a Class Identity.

Promotion is per Identity, not per Employee — every Main Class and Sub Class advances independently.

---

# Purpose

The Promotion System exists to:

- Recognize sustained growth over time
- Convert performance history into a formal advancement
- Provide a transparent, repeatable path
