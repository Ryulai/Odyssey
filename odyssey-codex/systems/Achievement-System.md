# Achievement System

## Definition

The Achievement System records and rewards memorable milestones in a member's Odyssey journey.

Achievements are permanent.
Once earned, they belong to the member forever.

---

# Purpose

The Achievement System exists to:

- Celebrate meaningful moments
- Build a personal story for every member
- Create long-term motivation beyond monthly cycles

---

# Current Concept

Two families of achievements are anticipated:

- **Identity Achievements** — exclusive to a single Class Identity
- **Global Achievements** — shared across every Identity

Final catalogue and unlock rules pending design.
